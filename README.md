# Fitness-Website

Live Website: https://fitnessaze.netlify.app/

I developed a personal fitness dashboard called FORMA to plan daily meals and look up workouts.


The tools i used for creating this website : 
**HTML5 & CSS3** - For the layout, text, and design.
**JavaScript** — For the calculator formulas and interactive buttons.
**Netlify** — To host the website live on the internet.

This website has several features such as : 
**Calorie Calculator:** Put in your age, height, and weight to see how many calories you need to eat each day.
**Exercise List:** Click on a muscle to see workouts that train that specific area.
**Photo Food Log:** Add a picture of your food to help track your daily meals.

Note : 
This website gives general fitness info. It is not medical advice. Always talk to a doctor before starting a new diet or workout plan
